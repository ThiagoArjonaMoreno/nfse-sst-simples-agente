# Checklist Prático de Emissão — NFS-e Nacional (Simples Nacional)

Use este guia antes de transmitir a nota para evitar contradições fiscais, técnicas ou contratuais entre os perfis (`TECNICO_SST`, `ERGONOMISTA` e `ENGENHEIRO_SST`).

## 1. Definição e Bloqueio do Perfil
- [ ] **Perfil definido:** Escolhi apenas um perfil (`TECNICO_SST`, `ERGONOMISTA` ou `ENGENHEIRO_SST`) para esta nota.
- [ ] **CNAE compatível:** O CNAE selecionado consta no CNPJ e pertence ao repertório compatível com o perfil ativo.
- [ ] **Sem contaminação cruzada:** Não misturei códigos, atribuições ou vocabulário de outro perfil na mesma emissão.

## 2. Classificação do Serviço e Operação
- [ ] **LC 116 e Complementar Municipal:** O item escolhido corresponde exatamente ao escopo entregue (consultoria/assessoria, treinamento, análise/perícia ou engenharia).
- [ ] **NBS compatível:** O código NBS está habilitado no portal para o item da LC 116 selecionado.
- [ ] **`cIndOp` conferido:** Utilizei `100301` como padrão geral ou o código específico (`100101` / `100201`) exigido pela tabela vigente para a operação.
- [ ] **Tomador correto (B2B):** Quando o serviço for prestado para uma consultoria contratante, o tomador da nota é a contratante — nunca o cliente final.

## 3. Auditoria do Texto da Descrição
- [ ] **Escopo fiel:** A descrição reflete o que foi efetivamente entregue (avaliação de SST, treinamentos, análise das atividades e/ou elaboração de documento técnico conforme escopo acordado com a contratante).
- [ ] **Termos proibidos ausentes:** Nenhum termo bloqueado para o perfil ativo aparece no texto (por exemplo, sem *"engenharia"* ou *"ART"* quando o perfil for `ERGONOMISTA` ou `TECNICO_SST`).
- [ ] **Redação limpa:** Texto objetivo, claro e sem informações contraditórias.

## 4. Tributação e Campos Fiscais (Simples Nacional)
- [ ] **ISSQN:** Apurado via Simples Nacional (PGDAS-D), sem retenção indevida.
- [ ] **PIS/COFINS:** Situação tributária `00 - Nenhum` e tipo de retenção `0 - PIS/COFINS/CSLL Não Retidos`.
- [ ] **Outras retenções:** IRRF, contribuições sociais retidas e contribuição previdenciária retida sem retenção indevida.
- [ ] **IBS / CBS:** `CST 000` e `cClassTrib 000001` (quando exigidos pelo emissor), com documentos referenciados em branco salvo exceção aplicável.
- [ ] **Valor aproximado dos tributos:** Configurado para informar a alíquota do Simples Nacional (com conferência do Fator R quando cabível).
